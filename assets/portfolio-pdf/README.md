# Editorial PDF assets

Server-only vector marks supplied by the product owner on 2026-10-17, matching
the approved editorial design proof. Do not use user-uploaded SVGs here.

Fonts are static instances of the Google Fonts Inter and Plus Jakarta Sans
variable fonts (400/500/600 and 600 respectively). Original OFL notices are in
`fonts/`; font names distinguish weight instances for embedded PDF rendering.
The runtime embeds subsets. No Python, font downloads, or operating-system
font paths are required in production.

The glyph check refuses unsupported text instead of silently dropping letters.
Additional script coverage is not yet bundled; such profiles receive a clear
download error without changing their saved name or public page.
